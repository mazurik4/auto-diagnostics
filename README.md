# Сайт «Автодіагностика — Київ»

Статический сайт майстерні автодіагностики: [autoworkshop.com.ua](https://autoworkshop.com.ua).
Публикуется через **GitHub Pages** из ветки `main` (адрес задаёт файл `CNAME`).
Серверная часть (заявки, новости, статистика) — в репозитории
[backend](https://github.com/mazurik4/backend).

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | главная страница: разметка, SEO-теги, структурированные данные (Schema.org, FAQ) |
| `style.css` | все стили (тёмная тема, зелёный акцент, мобильная версия) |
| `script.js` | вся логика: услуги/процесс/FAQ, подбор по симптому, форма заявки, карусель новостей, анонимная статистика |
| `admin.html` | закрытая страница управления новостями и статистикой (не индексируется) |
| `privacy.html` | политика конфиденциальности |
| `img/` | логотип, иконки, `og-image.jpg` (картинка для превью ссылок в Telegram/соцсетях) |
| `CNAME` | домен сайта для GitHub Pages |
| `robots.txt`, `sitemap.xml` | для поисковиков (`admin.html` закрыт от индексации) |
| `googleaf6ac6c544606013.html` | подтверждение владения сайтом в Google Search Console |

## Как менять содержимое

- **Услуги, этапы работы, «Чому ми»:** массивы `services`, `process`, `why` в начале `script.js`.
- **Симптомы в подборе:** массив `symptoms` в `script.js`.
- **FAQ:** блок `#faq` в `index.html` (и тот же текст в `FAQPage` в начале файла для Google).
- **Телефон, адрес, график:** в `index.html` (разметка и Schema.org) и функция статуса «працює» в `script.js`.
- **Цвета и шрифты:** переменные `:root` в начале `style.css`.

## Новости

Карусель показывает посты из Google-профиля компании, их подтягивает бэкенд.
Ручного добавления нет: опубликуйте пост **с фото и текстом** в Google-профиле, и он появится на сайте
(до 30 минут, или сразу по кнопке «Синхронізувати з Google зараз» в `/admin.html`). Подробности — в README бэкенда.

## Админка (`/admin.html`)

Вход по `ADMIN_KEY` (задаётся на Render). Внутри: синхронизация новостей, скрытие постов и
анонимная статистика (просмотры, источники, клики по кнопкам, симптомы). Ключ хранится только в
`sessionStorage` вкладки.

## Анонимная статистика

Без cookie и без IP. Не считаются визиты с `Do Not Track`, а также браузеры, где один раз
открыли сайт с `#notrack` в адресе. Подробности — в `privacy.html` и README бэкенда.

## Как опубликовать изменения

1. Изменить файлы.
2. GitHub → *Add file → Upload files* → загрузить изменённые файлы (в ту же папку) → *Commit changes* в `main`.
3. Через ~1 минуту сайт обновится (в браузере: Ctrl+F5, чтобы обойти кэш).
